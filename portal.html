Keffi Premier Academy students, parents, teachers, volunteers and authorized school administrators access their digital services through the SpeakOut Portal.

How registration works

One school. One unique code. The right access for every user.

When Keffi Premier Academy is registered on the SpeakOut Portal, the school receives a unique school code. New users enter that code during registration so their account is linked to Keffi Premier Academy.

1
Open the SpeakOut registration page
Select the appropriate account type.
2
Enter the Keffi Premier Academy unique school code
The code links the user to the correct school workspace.
3
Complete role-specific verification
Student, parent, teacher/volunteer and admin access should be verified differently.
4
Access the personalized portal
Users see only the services and information permitted for their role.
Important

The school website does not store student records.

Authentication, student records, parent linking, role permissions, reports and programme information remain inside the SpeakOut Portal. This website only provides the public-facing school experience and a secure route into the portal.
